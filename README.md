# F-4 Phantom longitudinal dynamics analysis

This repository documents my analysis of the **longitudinal flight dynamics of the F-4 Phantom aircraft** using **MATLAB and Simulink**.

The project focuses on modeling aircraft motion with **state-space methods**, analyzing system stability, and investigating dynamic response through simulation.

## Objectives

* Model the aircraft longitudinal dynamics
* Analyze stability characteristics
* Study system response using MATLAB and Simulink
* Interpret engineering behavior from simulation results

## Methods used

* State-space representation
* Transfer function analysis
* Eigenvalue analysis
* Time-domain simulation
* Simulink modeling
